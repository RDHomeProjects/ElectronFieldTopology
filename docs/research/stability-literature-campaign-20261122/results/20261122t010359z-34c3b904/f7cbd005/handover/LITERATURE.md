# Interpretation of motion

Uniform translation and internal rotation are different hypotheses. The unchanged continuum SF action is Lorentz invariant; a simple coasting profile is not a generic cure for an inadmissible rest profile. The finite lattice only approximates that covariance. A paired rest/boost screen is therefore conditional on measured static and boundary admission plus a two-grid consistency check. Internal rotation requires an appropriate constrained variational problem, not a velocity added to a failed static field.

# Model and numerical separation

The current action has a two-derivative sigma contribution plus a quartic term. A continuum scaling argument motivates E2/E4 diagnostics; finite box and nodal discretization effects mean E2=E4 is not an exact project gate. The scale sweep measures actual mapped-field energies and places additional samples near an interior fitted extremum. Main and tail residuals, mesh resolution and optimizer history are assessed separately. Nothing here identifies the neutral SF field with an electron or proves long-time stability.
