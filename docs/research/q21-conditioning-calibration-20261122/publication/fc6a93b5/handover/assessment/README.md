# Q21 scientific review — 23 November 2026

Open `ASSESSMENT.html` in a browser. The report contains the scientific interpretation, literature alignment and a staged Q2–Q32 recommendation. PNG figures are high-resolution and SVG copies are provided.

This is an assessment bundle, not a new numerical-run or publication handover. No production optimization, field modification or GitHub operation is performed. The original compact evidence is preserved unchanged at `data/completed-evidence.zip`; full fields remain on the workstation.

To reproduce the compact integrity/statistical review in an environment with Python and NumPy, run from this directory:

```bash
python3 -B review_archive.py data/completed-evidence.zip --output review-output
```

This verifies recorded gate decisions, response statistics and fitted-model selection. It does not replay full-field numerical metrics. The source archive and embedded handover are pinned before its fitting routines are imported. Results go to the new `review-output` directory.
